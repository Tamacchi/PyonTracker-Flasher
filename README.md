# PyonTracker Firmware Flasher

**[Download for Windows](https://github.com/Tamacchi/PyonTracker-Flasher/releases/latest/download/PyonTrackerFlasher.exe)** · [Release notes and ZIP](https://github.com/Tamacchi/PyonTracker-Flasher/releases/latest)

Windows 10/11, 64-bit. Run the EXE. Firmware is included; flashing works offline.

### Flash your trackers

1. Close SlimeVR Server and other serial apps. Connect your main tracker with a USB data cable and turn it on.
2. Wait for identification. If asked, select the IMU model printed on the lid.
3. Review your selection, then click **Flash**. Keep trackers powered on and connected until verification finishes.

Use **Help** in the app for connection guidance, or **Copy support details** when contacting Tamacchi.
